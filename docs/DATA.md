# Dataset notes

**Source:** UCI *AI4I 2020 Predictive Maintenance Dataset* — https://archive.ics.uci.edu/dataset/601/ai4i+2020+predictive+maintenance+dataset
**License:** CC BY 4.0 (cite: S. Matzka, "Explainable Artificial Intelligence for Predictive Maintenance Applications", 2020).
**Download:** `make data` (`pmip.download`), fetched from the official UCI static URL; nothing is bundled in the repo.

| Column | Use |
|---|---|
| UDI, Product ID | identifiers — **excluded** from features |
| Type (L/M/H) | feature (`machine_type`) |
| Air/Process temperature [K], Rotational speed [rpm], Torque [Nm], Tool wear [min] | features |
| Machine failure | **binary target** |
| TWF, HDF, PWF, OSF, RNF | failure-mode flags — **excluded from features** (they define the target => leakage); used only to build the failure-mode label |

## Limitations (important)
- The dataset is **synthetic**, generated by the authors to mimic real data. Results demonstrate a methodology, not plant performance.
- ~3.4% failures (strong imbalance); some modes have < 50 examples; the data has known label inconsistencies (failure flag without a mode, and the reverse for RNF), reported by `quality_report`.
- No timestamps and no machine ID => no chronological/grouped split and **no remaining-useful-life** estimation. The split is stratified random, which is optimistic versus real deployment.
- `UDI` is a row index, `Product ID` is quality variant + serial; neither identifies a physical machine.
- NASA bearing / C-MAPSS run-to-failure data would be the right extension for RUL; it is deliberately **not** claimed here.

`pmip.synthetic` generates an AI4I-*like* table for CI and smoke tests only. It is not the UCI data and its metrics must never be reported.
